# AI 工作流规则

## 开始任务

1. 先阅读根目录 [`AGENTS.md`](../../AGENTS.md) 和适用的 `docs/`。
2. 对新增 Intent 或 Session 状态的任务，加载对应 `.agent/skills/`。
3. 先确认变更范围；不因 AI 推断而扩展产品需求、数据迁移或外部行为。

## 执行与交付

1. 代码、测试和受影响的正式文档同步修改。
2. 提交前遵循 [`CONTRIBUTING.md`](../../CONTRIBUTING.md)：运行适用验证并使用规定的提交信息格式。
3. 交付时说明改动、风险或未覆盖项，以及实际执行过的验证。

## 边界

- 不把正式规则复制到 `.agent/`；引用 `docs/` 的唯一事实来源。
- 不提交密钥、Token、真实 MCP 连接凭证或用户数据。
- 不隐藏失败、跳过测试或以未验证的假设宣称任务完成。
