# Terminal Session 管理

## 步骤

1. 发送 `/reset`。
2. 发送 `打开终端`。
3. 发送 `打开终端` 一次，创建第二个 Shell。
4. 发送 `终端列表`，复制一个非当前终端 ID。
5. 发送：

   ```text
   /terminal <终端ID>
   ```

6. 发送 `关闭终端`。
7. 再次发送 `终端列表`。

## 预期结果

- 每次“打开终端”创建一个独立 tmux Shell，并尝试在 macOS Terminal.app 中打开。
- 终端列表能标记当前终端，并展示“运行中 / 已结束 / 已失效”。
- 使用 `/terminal` 后，指定终端成为当前终端。
- 关闭当前终端后，该终端不再可作为当前输入目标。
