# Session 上下文与并发消息

## A. 当前 Session 上下文

1. 在没有活动终端的初始会话中发送：

   ```text
   请记住，我的测试代号是蓝鲸。
   ```

2. 再发送：

   ```text
   我的测试代号是什么？
   ```

3. 发送 `新建会话`。
4. 在新会话再次询问测试代号。

## 预期结果

- 同一个 Agent Session 中，模型请求会携带最近 12 条 user / agent 对话，可理解前文。
- 新建会话后，旧 Session 的对话不会作为新 Session 的模型上下文。

## B. 同 chat 串行处理

1. 在活动 Shell 中快速连续发送两条消息：

   ```text
   查看当前目录
   确认
   ```

2. 观察两条消息的处理顺序。

## 预期结果

- 第二条“确认”会等待第一条模型请求和候选命令保存完成后才执行。
- 不应因为并发竞争而出现“当前没有等待确认的 Shell 命令”。
