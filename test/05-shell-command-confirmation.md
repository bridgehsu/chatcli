# Shell 自然语言命令确认

## 前置条件

- `router.enabled=true`，且模型 API Key 有效。
- 当前 Agent Session 已通过“打开终端”创建并选中普通 Shell。

## 步骤

1. 发送：

   ```text
   查看当前目录下有哪些文件
   ```

2. 不要立刻发送 Shell 命令，观察机器人回复。
3. 发送 `确认`。
4. 查看 Telegram 终端输出或本机 tmux 窗口。
5. 再发送一次自然语言请求，例如 `查看当前工作目录`，收到候选命令后发送 `取消`。

## 预期结果

- 中文请求不会原样发送给 zsh，不应出现 `command not found`。
- 机器人展示候选命令、简短说明以及“确认 / 取消”提示。
- 只有发送“确认”后，候选命令才会写入 tmux Shell。
- 取消后机器人明确说明不会执行任何操作。
