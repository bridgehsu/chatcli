# 工作目录与 CodeX / Cursor 启动

## 前置条件

- 本机已安装 `codex` 或 `cursor agent` 中至少一个。
- 准备一个真实存在的测试目录，例如项目根目录。

## CodeX 流程

1. 发送 `/reset`。
2. 发送 `CodeX`。
3. 收到“请发送要启动 CodeX 的工作目录”后，发送一个存在的绝对路径。
4. 发送 `终端列表`。

## Cursor 流程

重复上述步骤，将 `CodeX` 替换为 `Cursor`。

## 预期结果

- 选择 CLI 后，Session 状态进入“等待选择目录”。
- 合法目录会启动对应 CLI，并提示该终端已设为当前终端。
- 终端列表显示正确的类型、目录、状态和终端 ID。
- 在等待目录时发送无效路径，应提示重新发送目录路径或名称；发送“取消”应退出目录选择流程。
