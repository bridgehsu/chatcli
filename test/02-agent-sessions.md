# Agent Session 管理

## 目标

验证一个 Telegram chat 可创建多个 Agent Session，并且当前会话可切换。

## 步骤

1. 发送 `/reset`。
2. 发送 `新建会话` 两次。
3. 发送 `会话列表`，记录列表中的一个非当前会话 ID。
4. 发送：

   ```text
   /agent_session <记录的会话ID>
   ```

5. 再次发送 `会话列表`。
6. 发送 `关闭会话`，然后再次发送 `会话列表`。

## 预期结果

- 列表按“当前会话”和“其他会话”分区显示，ID 可复制。
- 切换后目标会话显示为当前会话。
- 关闭当前会话后，系统自动创建一个新的“初始化”当前会话。
- 已关闭会话不可再作为有效会话切换。
