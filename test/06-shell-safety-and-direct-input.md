# Shell 命令编辑、安全限制与直接输入

## 前置条件

- 已选中普通 Shell。
- 模型路由已启用。

## 步骤

1. 发送 `查看当前目录`，等待候选命令。
2. 发送：

   ```text
   修改为：ls -lah
   ```

3. 确认机器人重新展示候选命令后，发送 `确认`。
4. 再次生成候选命令，发送：

   ```text
   修改为：rm -rf test
   ```

5. 发送直接 Shell 输入：

   ```text
   $ pwd
   ```

## 预期结果

- 修改后的 `ls -lah` 仍需再次确认，确认后才执行。
- `rm -rf test` 被本地安全规则拒绝，不产生待确认状态。
- 模型候选命令只允许只读白名单命令；管道、重定向、命令替换也会被拒绝。
- `$ pwd` 不调用模型、不展示确认提示，直接发送到当前 Shell。

> `$` 或 `!` 是用户明确的手动输入入口，不受模型候选命令白名单限制；请只输入自己确认安全的命令。
